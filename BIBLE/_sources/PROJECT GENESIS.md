# PROJECT GENESIS
## Un univers artificiel vivant

> **Créer un monde.  
> Lui donner des règles.  
> Le laisser évoluer.  
> Puis découvrir ce qu'il devient.**
>
> Et quelque part, au-dessus de tout ça : **Dieu nous regarde.**

---

# 1. Philosophie fondamentale

## 1.1 L'histoire n'est pas écrite

Le projet ne doit pas contenir une histoire prédéterminée.

Il ne doit pas exister de scénario du type :

```text
Année 500 → agriculture
Année 1200 → première ville
Année 3000 → empire
Année 5000 → révolution industrielle
```

À la place, le moteur définit des **possibilités**.

Les événements résultent de :

- l'environnement ;
- les ressources ;
- les individus ;
- les mutations ;
- les décisions ;
- les interactions ;
- les connaissances ;
- les événements passés.

---

## 1.2 Le monde doit pouvoir nous surprendre

Une règle essentielle :

> **Le développeur ne doit pas connaître à l'avance l'histoire du monde.**

Si quelque chose d'intéressant arrive, ce doit être parce que le système l'a produit.

Une civilisation peut :

- prospérer ;
- stagner ;
- disparaître ;
- se diviser ;
- fusionner ;
- conquérir ses voisins ;
- être détruite par une catastrophe ;
- détruire elle-même son environnement.

Elle doit disposer d'un système suffisamment riche pour permettre l'apparition de structures complexes.

```text

E + E → F
```

Les molécules peuvent avoir différentes propriétés :

# 42. Règles d'or

### Règle 1

**Ne pas écrire l'histoire à la place du monde.**

### Règle 2

**Les systèmes doivent interagir entre eux.**

### Règle 3

**Les conséquences doivent être persistantes.**

### Règle 4

**Une technologie peut être oubliée.**

### Règle 5

**Une civilisation peut disparaître.**

### Règle 6

**Une croyance peut être fausse.**

### Règle 7

**Un habitant peut se tromper sur le fonctionnement du monde.**

### Règle 8

**Dieu peut intervenir, mais le monde décide de l'interprétation.**

### Règle 9

**Le développeur ne doit pas connaître les résultats à l'avance.**

### Règle 10

> **Si le système peut produire quelque chose que nous n'avions pas prévu, c'est une réussite, pas un bug.**

# 43. Question centrale

> **Si nous créons un univers avec suffisamment de règles simples, suffisamment de liberté et suffisamment de mémoire... quelle histoire écrira-t-il tout seul ?**

Et lorsque ses habitants lèveront les yeux vers le ciel :

> **Que se passera-t-il lorsqu'ils comprendront qu'ils ne sont peut-être pas seuls ?**

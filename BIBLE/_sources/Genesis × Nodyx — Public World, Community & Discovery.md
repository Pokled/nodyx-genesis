# Genesis × Nodyx — Public World, Community & Discovery

> **Genesis crée un monde vivant. Nodyx permet au monde d'être observé, raconté, discuté et découvert.**
>
> Le référencement n'est pas la finalité du système. Il est une conséquence naturelle de la quantité et de la richesse des événements produits par un univers persistant.

---

# 1. Vision

Genesis ne doit pas être uniquement une simulation exécutée sur un serveur privé.

À terme, il doit devenir :

> **un univers persistant que les humains peuvent observer.**

Les civilisations vivent leur propre histoire.

Les individus naissent, évoluent, communiquent, créent des sociétés, des religions, des économies, des technologies et des conflits.

Pendant ce temps, les humains peuvent observer cet univers depuis Nodyx.

---

# 2. Deux mondes qui se rencontrent

Genesis possède deux populations :

```text
                    GENESIS
                       │
             ┌─────────┴─────────┐
             │                   │
             ▼                   ▼
        Habitants              Humains
             │                   │
             │                   │
             ▼                   ▼
       Monde simulé            Nodyx
```

Les habitants vivent dans la simulation.

Les humains vivent dans Nodyx.

Nodyx devient leur fenêtre sur Genesis.

---

# 3. Nodyx comme observatoire

Nodyx ne doit pas être uniquement une plateforme communautaire classique.

Il peut devenir :

> **l'observatoire social de Genesis.**

Les utilisateurs peuvent :

- observer une civilisation ;
- suivre un individu ;
- suivre une planète ;
- consulter une timeline ;
- lire les événements historiques ;
- découvrir les religions ;
- suivre les guerres ;
- observer les découvertes scientifiques ;
- discuter des événements ;
- créer des communautés autour des civilisations ;
- commenter les décisions historiques ;
- comparer différentes sociétés.

# 10. Éviter le contenu artificiel

Il faut absolument éviter :

```text
100 000 pages identiques
+
texte générique
+
mots-clés artificiels
=
SEO médiocre
```

Chaque page publique doit correspondre à une véritable donnée ou un véritable événement du monde.

Une page doit avoir une raison d'exister.

---

# 11. Canon historique

Genesis doit distinguer :

### État actuel

Ce qui existe maintenant.

### Histoire

Ce qui s'est produit.

### Archives

Ce qui a été observé ou enregistré.

### Interprétation

Ce que les habitants pensent de leur propre histoire.

### Observation humaine

Ce que les utilisateurs Nodyx pensent de cette histoire.

Cela permet d'avoir plusieurs niveaux de lecture.

---

# 12. Le paradoxe intéressant

Un événement peut avoir plusieurs versions.

Exemple :

```text
FAIT SIMULÉ

Roi Arven meurt en 8 432.
```

Mais :

```text
VERSION OFFICIELLE

"Le roi est mort paisiblement."
```

```text
VERSION RELIGIEUSE

"Les dieux l'ont rappelé."
```

```text
VERSION POPULAIRE

"Il a été assassiné."
```

```text
OBSERVATION NODYX

Les utilisateurs débattent de la cause réelle.
```

Genesis peut donc produire une histoire beaucoup plus intéressante qu'une simple base de données.

# 13. SEO technique

Le site public doit être conçu pour être correctement indexable.

Objectifs :

- URLs stables ;
- pages publiques accessibles ;
- titres uniques ;
- descriptions pertinentes ;
- données structurées ;
- sitemap ;
- liens internes ;
- canonicalisation ;
- pages d'archives ;
- timeline indexable ;
- contenu rendu côté serveur lorsque nécessaire ;
- performances web élevées.

Le contenu généré doit être organisé hiérarchiquement.

```text
Genesis
│
├── Civilisations
│   └── Civilisation A
│       ├── Histoire
│       ├── Dirigeants
│       ├── Villes
│       ├── Technologies
│       └── Guerres
│
└── Événements
    ├── Guerre X
    ├── Découverte Y
    └── Traité Z
```

L'utilisateur doit pouvoir se perdre dans l'histoire.

> **"Je suis venu voir une guerre et trois heures plus tard je lis l'histoire d'une religion née 7 000 ans auparavant."**

# 21. Le rôle du "Dieu"

Le créateur de Genesis dispose d'un statut particulier.

Il peut observer l'univers.

Il peut éventuellement :

- intervenir ;
- provoquer un événement ;
- influencer une civilisation ;
- envoyer un message ;
- modifier certains paramètres ;
- rester totalement silencieux.

Mais les conséquences doivent être intégrées à l'histoire.

Si le Dieu intervient :

```text
Intervention
     ↓
Témoins
     ↓
Interprétation
     ↓
Religion
     ↓
Culture
     ↓
Histoire
```

Une simple intervention peut avoir des conséquences pendant des milliers d'années.

# 26. Ambition

Genesis × Nodyx doit progressivement devenir quelque chose qui ressemble à :

**un jeu vivant + une simulation + une histoire générative + un réseau social + une encyclopédie dynamique.**

Un visiteur ne vient pas simplement "jouer".

Il vient découvrir :

> *"Qu'est-ce qui s'est passé dans ce monde depuis la dernière fois que je suis venu ?"*

Et cette question doit avoir une réponse différente chaque jour.
